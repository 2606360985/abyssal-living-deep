# ABYSS//MINER — M2–M7 开发计划

## 总目标与约束

在 M1 工业 ROV 视觉基座上完成一个 3～5 分钟、可从头到尾游玩的深海采矿探索 Vertical Slice。最终流程为：下潜片段 → 深海抵达 → 主动声呐 → 发现结核矿区 → 采样与估值 → 巨大移动目标逼近 → 信号丢失 → 标题。

视觉、悬念与操作反馈仍高于系统完整度。后续不增加背包、经济循环、技能树、剧情对话、存档、复杂碰撞或通用任务编辑器。M2–M7 继续使用 WebGL2；WebGPU/TSL 迁移放在 Vertical Slice 完成之后，避免同时重写材质和玩法。

M1 基线为 RTX 2060、原生 1920×1080、DPR 1、60 秒中位 16.7 ms/P95 16.8 ms、233 次提交和约 105 万个含阴影 pass 的三角形。该数据证明能稳定跟随 60Hz，但不等同于有充足 GPU 余量。新增重特效必须具备单独开关，并在每个 Milestone 结束时重新测试。

## 先建立的公共骨架

M2 开始时先补一层轻量演出控制，后续阶段只向它注册内容：

- `SequenceDirector` 保存当前阶段、阶段内时间和一次性事件。阶段固定为 `descent`、`arrival`、`sonar`、`nodules`、`sampling`、`contact`、`lost`，数字键 1–7 直接进入对应阶段。
- 每个阶段实现 `enter(context)`、`update(dt)`、`exit()`；`enter` 必须重置 ROV、镜头、HUD、音频、粒子和目标状态，使阶段可重复录制。
- `GameState` 只保存流程需要的数据：当前阶段、声呐冷却、已发现 POI、当前样本、未知目标距离和输入锁定状态。不做通用 ECS。
- `AudioBus` 按 `ambience`、`vehicle`、`ui`、`impact` 四组控制 Web Audio 节点；首次键鼠输入后解锁声音。音频全部程序生成或来自明确授权的本地素材。
- `HUD` 改为状态驱动的工业显示组件；玩法代码只更新数据，不直接操作 DOM 动画。
- `QualityProfile` 增加 `high/medium/low` 三档，分别控制散射分辨率与步数、颗粒量、泥沙量、声呐显影分辨率、阴影和 Bloom。默认仍以 high 录制。

任务仪表距离和局部渲染距离分层：HUD 中首次接触为约 205m，但矿区在局部世界中布置于约 105–120m；抵达过程通过路线弯折、相对航速压缩和一次受控的黑暗过渡保持可信。声呐距离属于任务解算值，不直接等同于 Three.js 世界坐标。这样可以保留当前 320m 有限场地与远景遮蔽，并在 3～5 分钟内完成体验。

## M2 — 水体、泥沙与 ROV 操作质感

### 目标

让静态截图之外的连续 20–30 秒运动也可信：ROV 有重量，水体在移动，靠近海床会留下明显但可控的泥沙扰动。

### 实现

- 将 `Motion` 扩展为局部前进/侧移/升降速度、角速度、加速度限制和二阶阻尼；前进、倒车和升降使用不同响应参数。松键后保留短暂滑行，快速反向输入先减速再反向。
- 推进器转速、叶片模糊强度、机体轻微俯仰/横滚、灯架振动根据实际推力计算。相机跟随目标使用独立弹簧，碰到海床或快速制动时只产生一次低幅反馈。
- 把 marine snow 分成近、中、远三层。近层颗粒较大且快速穿过镜头，中层受灯束显影，远层极稀疏；三层均平滑回绕，不能在屏幕中跳变。
- 新增 GPU 粒子泥沙池。仅当下向推进器距海床低于约 5m 且推力有效时发射；粒子从海床法线附近扩散、先贴地翻滚再缓慢上升，并随时间消散。
- 加入薄层海床雾和极低频密度变化；继续使用深度裁切，避免雾穿透机体和岩石。
- 增加程序化推进器低频声、伺服声和水下结构噪声。默认音量克制，声音关闭时不创建持续振荡节点。
- 给第三人称跟随镜头增加简单的海床/大型岩石遮挡修正，只移动相机，不计算 ROV 与单块岩石的物理碰撞。

### 验收

- 连续前进、急停、转向、升降各录制 10 秒，运动不能像无人机，镜头不追尾穿地或被近景岩石长期挡住。
- ROV 高度 2m、4m、8m 三档测试：泥沙强度随高度合理衰减，8m 时基本不出现；停止推进后泥沙在数秒内散去。
- 颗粒不能在灯外形成均匀星空，也不能在相机附近突然出生或消失。
- high 档 1080p 连续运动 60 秒无 console/shader 错误，P95 不高于 22ms；若超预算，依次降低泥沙池数量、散射步数和阴影更新频率，不降低 ROV 材质质量。
- 通过以上动态画面验收后才进入 M3。

## M3 — 主动声呐

### 目标

Space 触发的声呐既是玩法输入，也是整支视频第一个强视觉记忆点；声呐必须与真实地形和目标发生空间关系。

### 实现

- `SonarSystem` 管理冷却、发射时间、回波目标和一次扫描结果。默认冷却 4 秒；按住 Space 不连续触发。
- 发射反馈依次为：短促机械按键声 → 低频 PING → ROV 周围世界空间波前扩张 → 被扫到的地形与岩石短暂显影 → HUD 数据逐项锁定。
- 用独立低分辨率 sonar mask/depth pass 渲染地形、岩石和 POI。合成时按世界距离形成扩张环，并用法线/深度边缘显示青绿色轮廓；不修改正常 PBR 材质。
- 地形显影控制在 1.5–2 秒内衰减。距离波前较远的区域保持黑暗；波前经过时 marine snow 短暂受扰动。
- 第一次有效扫描固定发现任务距离 205m 的 `UNKNOWN CONTACT`，显示 bearing、distance、estimated size、confidence、classification。bearing 来自 ROV 朝向与目标方向；HUD 数值按扫描瞬间锁定，不持续实时追踪。
- POI 在世界中只显示克制的方位括号/声呐残影，不画永久导航射线。后续 ping 可更新距离与置信度。
- 程序化 PING 使用短正弦扫频、延迟回波与低频尾音；视觉波前与音频起点误差应小于一帧。

### 验收

- 无 HUD 截图仍能看出一次扫描正在沿真实海床传播；有 HUD 时观众能在两秒内理解“发现了右前方未知目标”。
- 波前必须被地形深度正确遮挡，不能穿过前景岩石整片显影背后内容。
- 在 ROV 朝向 0°、±90° 和不同位置触发，bearing/distance 计算正确；冷却、长按、失焦、阶段切换不会重复触发。
- 对比 sonar pass 开/关的 GPU 成本；M3 1080p P95 仍不高于 22ms。扫描瞬间允许单帧轻微峰值，但不能连续卡顿。

## M4 — 多金属结核矿区与矿石扫描

### 目标

把“不起眼的黑色石头很值钱”做成清晰的发现时刻，并提供机械臂采样的明确目标。

### 实现

- 在目标区域生成确定性的结核密度场，使用 2–3 组低模球状几何和 `InstancedMesh`，约 2,000–4,000 个可见实例；近处实例有细微色泽与粗糙度差异，远处合并为密度纹理/较低实例密度。
- 矿区地形设计为一条灯光能扫过的缓坡和浅沟，避免结核被大型岩石完全遮住。接近约 18m 时进入矿区状态并显示 `POLYMETALLIC NODULE FIELD`。
- 声呐扫描矿区时显示更密集的点云/表面响应；普通光照下保持暗、低反射，只有湿润边缘出现轻微高光。
- 中心采样区生成 5–8 个可交互结核，每个带固定质量、Ni/Co/Cu/Mn 比例与估值。组成数据游戏化但总和一致；同一 seed 和结核 ID 必须复现。
- 准星靠近可采样目标且距离小于约 4m 时，用细小角标提示 `SAMPLE CANDIDATE`；不做自由拾取列表。
- 扫描后 HUD 分两步显示：先分类和置信度，再显示成分和 Estimated Value，突出黑石头与高估值的反差。

### 验收

- 从 30m 外到 4m 内的接近过程，矿区密度逐渐可读且没有明显批次弹出。
- 1080p 主镜头中至少能同时看到 ROV、灯光和大量结核，但界面不会把场景遮成网页面板。
- 不同朝向和位置只能锁定视锥内、未被地形遮挡且在距离范围内的目标。
- 扫描结果可复现，实例量不会令 P95 超过 22ms。

## M5 — 机械臂采样

### 目标

实现一次短、清晰、可信的抓取演出。操作只要求玩家瞄准并确认，不制作复杂机器人模拟器。

### 实现

- 将 M1 折叠机械臂拆成肩、肘、腕、爪四个可动画关节，保留液压缸和软管挂点；用解析两骨 IK 求肩肘，腕部对准结核法线，超出可达范围时禁止采样。
- 当有效目标被锁定时，按交互键启动不可中断的 5–7 秒状态机：`aim → extend → approach → close → lift → retract → stow`。ROV 在过程中进入低功率定点保持，只允许轻微姿态漂移。
- 抓取目标在爪闭合帧从实例池隐藏，并生成一个附着于机械爪的独立 mesh；收回后隐藏该 mesh，写入样本数据。阶段重置恢复实例状态。
- 抓取接触点释放一次局部泥沙脉冲，配合爪闭合、液压、金属接触声和幅度极低的镜头反馈。
- HUD 先显示 `SAMPLE ACQUIRED`，随后逐项显示 Mass、Composition、Estimated Value；所有数据来自 M4 的目标记录。
- IK 或路径无法安全到达、目标丢失、距离过远时只给短促拒绝反馈，不启动半套动画。

### 验收

- 从三个允许的目标位置重复抓取，爪尖不明显穿过海床，结核不会悬空、复制或在收回后留在原处。
- 抓取过程中切换 HUD、性能显示不影响状态；数字键跳阶段能完整清理动画和临时 mesh。
- 录制侧面、前侧和机械臂近景，动作具有重量，软管没有严重脱离挂点。
- 完整抓取期间帧率、光束和泥沙稳定；采样完成后才能触发 M6。

## M6 — 未知目标、干扰与结尾

### 目标

用声呐、距离变化和极少量视觉信息制造高潮；未知生物不完整展示。

### 实现

- 采样完成 4–6 秒后激活 `UnknownContact`。它只保存方位、任务距离、估算尺寸、速度和威胁阶段，不创建完整怪物模型。
- 连续有效扫描按演出更新为约 184m、162m、137m、108m；HUD 显示 `EST. SIZE > 40m`，classification 保持 `UNKNOWN MOVING CONTACT`，confidence 逐步上升后在干扰中下降。
- 声呐 mask 中用多段程序曲线、稀疏点云和被裁切的大尺度深度轮廓构成不完整回波。每次只显示局部，轮廓不能拼成完整生物外形。
- 正常灯光中默认看不到目标。最终阶段仅允许一次 6–10 帧、低对比度、被颗粒和雾遮挡的远处巨大剪影；它由简单遮挡体组成并在出现后永久禁用。
- 干扰按固定曲线升级：轻微声呐噪点 → 灯光偶发闪烁 → HUD 行扫描错位 → 音频丢包和低频冲击 → 摄像机短促 glitch。效果不能持续高频抖动。
- 结尾锁定输入，灯熄灭，信号噪声迅速压黑；先显示 `SIGNAL LOST`，停顿后显示 `ABYSS//MINER`。按 2 或数字阶段键可退出结尾并完全恢复渲染状态。

### 验收

- 不看正常画面，只看声呐与数值也能理解目标正在快速逼近；关闭 HUD 后仍保留悬念，但不会清楚看到怪物。
- 四次距离更新顺序固定，阶段重置后可复现；重复按 Space 不跳过必须的节奏节点。
- 闪烁和 glitch 不使用大面积高频白闪；提供 `prefers-reduced-motion` 路径，降低镜头与界面位移但保留剧情信息。
- 从采样完成到标题完整录制，音画同步、无残留灯光或 HUD，结尾黑位稳定。

## M7 — 完整流程、声音、Showcase 与性能收尾

### 目标

把六个独立系统整合为一个 3～5 分钟可以交付录屏的完整体验，并让所有阶段都能快速复现。

### 实现

- 完成数字键 1–7：1 下潜、2 深海抵达、3 声呐、4 矿区、5 机械臂、6 未知目标、7 信号丢失。每个入口设置正确的前置状态，不要求先走完整流程。
- 增加 20–30 秒下潜开场：外部近景、逐渐消失的上方微光、深度快速增加、金属结构声和最终完全黑暗；通过遮暗与相机演出复用 M1 场景，不生成从海面到 3800m 的连续地图。
- `SequenceDirector` 串起完整节奏，目标总时长约 3 分 40 秒：下潜 25秒、抵达/熟悉操作 35秒、首次声呐与接近 55秒、矿区扫描 35秒、采样 35秒、未知目标 55秒、结尾 20秒。玩家行动较慢时允许适度延长，但关键事件不因超时自动替玩家完成。
- 完整混音：深海底噪、推进器、伺服、声呐、泥沙、机械臂、干扰和结尾冲击。首次交互解锁音频，提供静音键；录制模式允许 URL 参数预先设置音量但仍遵守浏览器自动播放限制。
- 打磨 Cinematic Camera 为阶段相关镜头，而非单一环绕；F4 在当前阶段的 2–3 个镜头间切换。F3 自由镜头保留，阶段逻辑继续运行但不移动 ROV。
- 扩充 QA 脚本：逐阶段截图、完整流程录制、阶段幂等重置、音频节点泄漏、WebGL 资源数量、长时间粒子稳定性、不同宽高比和 high/medium/low 性能。
- 将 Debug/Showcase 提示只放在开发 HUD；F1 后画面完全干净。制作最终默认 HUD、无 HUD、机械臂近景、声呐和结尾五组录屏预设。
- 最后统一色调、Bloom、文字时序、输入提示和声音响度；不在 M7 增加新玩法。

### 最终验收

- 新玩家无需口头说明可从开始玩到标题，流程实际时长落在 3～5 分钟。
- 第一帧深海主镜头仍满足 M1 的 ROV 辨识标准；声呐、矿区、抓取、未知目标和标题各有一张可单独使用的画面。
- 数字键 1–7、F1–F4 在任意阶段反复切换 20 次，无重复对象、残留音频、卡死状态或内存持续上涨。
- RTX 2060 high 档原生 1080p：常规段落 P95 ≤ 22ms，完整流程不得出现持续三帧以上超过 33ms；console/shader error 为 0。medium 和 low 至少在目标硬件模拟或降档测试中维持可玩。
- 完成 Chrome 与 Edge 的 WebGL2 回归、窗口失焦/恢复、刷新、音频未授权、reduced motion 和 16:9/9:16 构图检查。竖屏仅保证录制安全区和可理解性，不重做完整移动端操作。
- 形成最终 README、控制说明、性能报告、已知限制、五组关键截图和一条完整流程录屏。

## 推荐推进节奏

| Milestone | 建议投入 | 核心交付物 | 进入下一阶段的唯一门槛 |
| --- | ---: | --- | --- |
| M2 | 3–5 天 | 运动、颗粒、泥沙、基础声音 | 连续运动画面可信且性能合格 |
| M3 | 4–6 天 | 世界空间主动声呐 | 声呐本身值得截图/录屏 |
| M4 | 3–4 天 | 结核矿区、扫描与估值 | 矿区发现时刻清楚且有反差 |
| M5 | 4–6 天 | IK 机械臂与一次完整采样 | 三个目标位置抓取稳定可信 |
| M6 | 3–5 天 | 未知目标、干扰、结尾 | 不展示怪物仍能形成高潮 |
| M7 | 4–7 天 | 完整流程、音频与录制包 | 3～5 分钟端到端验收通过 |

预计总投入约 21–33 个有效开发日。每个阶段先做最小可见原型，再进行固定镜头截图、实际运行观察、console 检查和性能采样；视觉门槛未通过时不提前开始下一个 Milestone。
